# 数据库设计

数据库文件：`data/app.db`（SQLite），用 SQLAlchemy ORM 定义在 `models.py`。

## 数据表清单

| 表名 | 用途 | 关键字段 |
|---|---|---|
| `users` | 教师账号（预留多人） | username, password_hash, name |
| `classes` | 行政班 | name, grade, note |
| `students` | 学生 | student_no, name, gender, class_id |
| `class_sport_bindings` | 班级-运动项目关联配置（由学生名册班级管理多选维护） | class_id, sport_item（class_id + sport_item 唯一） |
| `class_periods` | 课时（手动添加 / 教学进度表导入） | class_id, order_no(课次), name, content, week, section, hours, homework, course_name, sport_item, location, note, source_file_id, source_type |
| `schedule` | 教师课表 | course_name, day_of_week, start_time, end_time, class_id, location |
| `attendance` | 考勤 | schedule_id, student_id, date, status |
| `rollcall_records` | 随机点名记录 | class_id, student_id, mode |
| `reflections` | 教学反思 / 听课记录 | kind, title, content, class_id, course_name, date, lesson_plan_id |
| `todos` | 教师待办 | title, category, done, due_date |
| `resources` | 教学资源（资料库） | name, category, file_path, link, note |
| `lesson_plans` | 教案（含版本） | group_id, version, title, subject, content(JSON) |
| `student_learning` | 学情分层记录 | class_id, sport_item, period_id, student_id, fitness_score, skill_score, level |
| `layered_assignments` | 分层作业（专项作业） | period_id, sport_item, level, content |
| `learning_sheets` | 学习单 | lesson_plan_id, phase(课前/课中/课后), content |
| `fitness_records` | 体测数据与成绩 | 原始测量值 + 各单项分 + total_score + grade |
| `fitness_standards` | 国标评分表 | item, gender, grade_group, score, value |
| `action_analyses` | 动作诊断 | student_id, sport_type, video_path, frames(JSON), result(JSON) |
| `grade_settings` | 平时成绩分值分配 | key(attendance/answer), name, weight(分值，和为100) |
| `student_grades` | 平时成绩 | student_id, term, attendance_score, answer_score, total |
| `settings` | 系统设置(key-value) | key, value |

## 关系要点
- 学生归属班级：`students.class_id → classes.id`。
- 课表绑定班级：`schedule.class_id → classes.id`。
- 班级-运动项目绑定：`class_sport_bindings.class_id → classes.id`，`sport_item` 为运动项目名称；一个行政班可绑定多个运动项目，由学生名册「班级管理」新增/编辑班级时多选维护。
- 课时归属班级：`class_periods.class_id → classes.id`，由教师工作台「教学进度」按行政班维护；可手动添加或教学进度表导入，导入课时 `source_file_id` 关联 `resources.id` 溯源原始文档，`source_type` 枚举 `manual`（手动）/ `schedule_import`（进度表导入）。资源库进度表资源可反向查「已同步至某班级」。
- 学情分层按三元组隔离：`student_learning.class_id + sport_item + period_id`（行政班 + 运动项目 + 课时）；解绑/改绑、删除课时不会删除历史分层记录（归档保留）。
- 考勤绑定课表与学生：`attendance.schedule_id / student_id`。
- 教案版本：同一教案用 `group_id` 关联，`version` 递增；修订 = 新增一行同 group_id、version+1。
- 体测记录每学年一条：`fitness_records.student_id + year` 可唯一。
- 平时成绩：满分 100 = `attendance_score + answer_score`，各自上限为 `grade_settings` 里的分值。
