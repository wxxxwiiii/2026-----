# DeepSeek 密钥申请指南

> 说明：DeepSeek 的 API 是付费服务，但价格很低，普通个人使用一个月通常几块钱以内。

## 申请步骤
1. 打开官网 <https://platform.deepseek.com/>（中文界面）。
2. 点击「注册 / 登录」，用手机号或邮箱注册账号。
3. 登录后进入控制台，找到「API Keys（API 密钥）」页面。
4. 点击「创建 API Key」，给密钥起个名字（如 `教学平台`），创建后会显示一串以 `sk-` 开头的密钥。
5. **复制并妥善保存**（密钥只显示一次，关闭后不再完整显示）。
6. 回到本系统「系统设置」页，把密钥粘贴到「DeepSeek API 密钥」框里保存。

## 充值（可选，按需）
- 在控制台「充值」页面充值少量金额（例如 10 元）即可长期使用。
- 若只做少量测试，可先充最小金额。

## 注意事项
- 密钥相当于密码，不要发给他人，也不要写进代码或提交到公开仓库。
- 若密钥泄露，可在控制台删除并重新创建。
- 本系统密钥仅保存在你本机 `data/app.db`，不会上传到别处。
