# 运行与验证指南

## 1. 首次运行
1. 安装 Python 3.10 及以上（安装时勾选 "Add Python to PATH"）。
2. 双击项目根目录下的 `start.bat`。
3. 首次会自动安装依赖（几分钟），然后启动服务并自动打开浏览器 `http://127.0.0.1:5000`。
4. 用默认账号登录（见登录页提示），进入后到「系统设置」粘贴 DeepSeek API 密钥。
5. 关闭运行窗口即停止程序；下次再次双击 `start.bat` 即可。

## 2. 数据备份
- 全部数据都在 `data/` 目录，**备份 = 直接拷贝 `data/` 文件夹**。

## 3. 验证路径（分模块）
- 教师工作台：导入班级名册 → 建课表 → 写教学反思/听课记录/待办 → 保存并刷新查看。
- 课堂助手（2 个子页面）：学生考勤＋随机抽提问（对某班考勤 → 随机抽学生提问）；学生平时成绩（选班级+学年筛选 → 核算平时成绩 → 导出 Excel）。
- 备课台：上传教学资源 → 输入主题生成教案 → 基于反思修订 → 查看版本回溯 → 生成一体化学习单。
- 体质健康：导入体测 Excel → 看自动评分与图表报表 → 查看体质预警。
- 动作识别（6 个子菜单）：上传视频（单条/批量，选项目+技术动作，批量按文件名匹配学生）→ 识别历史（筛选/查看视频/删除/单条导出）→ 常见错误汇总（三级筛选、错误频次图表、按错误类型分组、点学生名跳转弹窗、导出汇总 PDF）→ 动作诊断报告库（筛选/预览/下载/批量导出）→ 专项训练方案（基于汇总生成/保存/导出）→ 学生动作成长档案（时间线 + 关节角度趋势 + 错误演变）。

## 4. 常见问题
- 打不开页面：确认 `start.bat` 窗口仍在运行，浏览器地址为 `http://127.0.0.1:5000`。
- 端口被占用：可修改 `app.py` 里的 `port` 再启动。
- AI 功能报错：检查系统设置里是否已填写正确的 DeepSeek API 密钥，且网络可访问 DeepSeek。
