# 开发计划与执行步骤

## 执行原则
1. 每阶段只做该阶段任务，做完自测并停下向用户汇报，确认后再进入下一阶段。
2. 每阶段结束更新 `开发日志/YYYY-MM-DD.md` 与 `开发日志/TODO.md`。
3. 每阶段保持可运行、可回退。

## 阶段清单与验收标准

### 阶段 0 — 治理与骨架（已完成）
- 建 `CLAUDE.md`、`docs/`（7 份）、`开发日志/`。
- 建代码骨架、数据库建表、登录页、米色+淡蓝主题框架、DeepSeek 密钥设置页。
- 安装 Python 并跑通登录。

### 阶段 1 — 教师工作台
- 教师课表、学生名册（导入/分班）、教学反思、听课记录、教师待办。
- **验收**：能导入名册、建课表、写反思与听课记录、建待办并正确保存/展示。

### 阶段 2 — 课堂智能助手
- 学生考勤、随机抽学生提问、平时成绩（考勤+答题，比例可调，满分100）。
- **验收**：能对某班考勤、随机点名、按可调比例核算平时成绩并可视化。

### 阶段 3 — 体质健康分析
- 历史数据导入 + 现场录入、国标评分、图表呈现、体质预警。
- **验收**：导入体测数据后能自动评分、出图表报表、触发体质预警。

### 阶段 4 — 智能备课台
- 教学资源（资料库）、AI 教案生成与修订、版本回溯、配套学习单。
- 班级-运动项目关联配置与课时管理：学生名册「班级管理」多选绑定运动项目、「课时管理」按班维护课时；学情分层按「行政班 + 运动项目 + 课时」三元组；AI 依据运动项目生成专项分层作业。
- 教学进度表上传导入：资料库上传标准 Excel 进度表（兼容旧 Word）批量同步至课时管理。
- **验收**：能上传/管理教学资源、生成教案、修订并存版本、生成一体化学习单；能在班级管理绑定运动项目并按三元组做学情分层与专项作业生成。

### 阶段 5 — AI 动作识别（6 个子菜单）
- 上传视频（单条 + 批量异步队列 + 技术动作 + MediaPipe 状态）、识别历史、常见错误汇总（按错误类型归类 + 跨技术合并 + 三级筛选）、动作诊断报告库、专项训练方案（基于错误汇总生成/保存/导出）、学生动作成长档案（时间线 + 关节角度趋势）。
- 单人诊断弹窗 `renderActionModal` 为公共组件，多页共用。
- **验收**：六个子菜单均可访问与正常渲染；上传视频后能抽帧、给出中文纠错建议；批量上传显示进度与失败清单；错误汇总按错误类型归类并含涉及技术动作、可跳转单人弹窗、导出 PDF；报告库可预览/下载/批量导出；训练方案可生成/保存/导出；成长档案展示时间线与关节角度趋势。
