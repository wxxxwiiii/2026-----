# 开发日志 2026-09-18

## 已完成

### 班级-运动项目关联配置（整合进班级管理）
- 数据表 `class_sport_bindings`：`class_id + sport_item` 唯一，一个行政班可绑定多个运动项目。
- 绑定维护从「独立标签页」改为「教师工作台 → 学生名册 → 班级管理」：班级列表新增「运动项目」列；「新建/编辑班级」弹窗支持多选绑定运动项目（复用 `appModal` 弹窗 + `sport-check` 多选框）。
- `SPORT_ITEMS` 枚举上移到 `models.py`，供班级绑定、教案、学情分层共用（单一数据源）。

### 课时管理（学生名册同级子模块）
- 新增数据表 `class_periods`：教师按行政班维护课时（课时名称、排序、备注）。
- 学生名册页面新增「课时管理」卡片（与「班级管理」同级），独立班级选择器、添加/删除课时；删除课时不删除历史分层记录（归档保留）。
- 学情分层「关联课时」下拉数据源改自课时管理（原为教案），未配置课时提示前往课时管理。

### 学情分层作业中心（三元组绑定）
- 学情分层按「行政班 + 运动项目 + 课时」三元组隔离（`student_learning` 新增 `sport_item`、`period_id` 字段，含轻量迁移）。
- 运动项目下拉数据源取自该班绑定记录；分层页不允许直接新增绑定；未绑定项目时提示「前往教师工作台 → 学生名册 → 班级管理」配置。
- 历史分层数据归档保留：解绑/改绑运动项目、删除课时均不删除既有分层记录（按三元组归档在库）。
- AI 生成读取运动项目输出「专项分层课后作业」，并带上课时；体能拓展方案同步带上运动项目与课时；保存分层作业时记录运动项目与课时。

### 顺带修复
- 分层等级命名统一为「基础层 / 提升层 / 进阶层」（原前端用「巩固层 / 提高层」，导致 AI 人数统计恒为 0）。

### 教学进度表上传导入
- 资料库新增「上传教学进度表」按钮 → 弹窗仅选择文件（xlsx / doc / docx），系统自动识别表格。
- 识别后进入预览页：先预览课时列表，再在预览页选择绑定班级/课程名称/授课项目/授课地点与导入模式（元数据后置，不再在上传时预选）。
- 标准模板 7 列（课次、授课内容、星期、节次、本次学时、作业、备注），课程/项目/场地不写表内；授课项目→场地映射自动带出（`SPORT_VENUES`，13 项 + 4 项课程名称）。
- 解析：Excel 按表头识别；旧版 Word 按「周次/讲授章节及内容」智能解析（含课时→本次学时映射）并提示核对；异常校验（缺列、课次非数字/重复、内容为空、超 50 条）。
- 预览页：课次/授课项目/授课地点可单行编辑；追加模式课次与该班现有课时冲突时高亮并禁止导入（`/periods/class-existing` 动态读取），服务端二次拦截。
- 确认导入：批量写入课时管理，`source_type='schedule_import'`、源文件归档资源库（`source_file_id`）。
- 双向溯源：课时管理导入课时提供「溯源」跳原始文件；资源库进度表资源显示「已同步至某班」并可跳转课时管理。
- 课时管理：手动/导入课时混合展示，支持编辑（`period_edit`）与删除，课次升序、授课内容展开收起、扩展展示星期/节次/学时/作业/备注。
