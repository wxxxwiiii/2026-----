# 设计规范（UI）

## 1. 整体风格
简洁、直观、简约的国内教育系统风格。圆角卡片 + 轻微阴影，**无花哨动画**，信息密度适中。

## 2. 整体布局（四区）
1. **左侧**：永久固定侧边菜单栏，菜单可分组折叠，菜单项前置图标，当前页面高亮。
2. **顶部**：全局导航栏，含系统名称、全局搜索框、AI 入口、配色设置、工作台编辑、学期周信息、消息通知、用户头像。
3. **中间主内容区**：卡片式布局（圆角卡片、轻微阴影），随侧边栏切换内容。
4. **页面底部**：快捷功能图标栏 + 常用 AI 工具快捷入口。

## 3. 配色（默认：米色为主 + 淡蓝点缀，支持切换）
| 用途 | 默认（米色）色值 |
|---|---|
| 页面背景 | `#f5f1e8` |
| 侧边栏 | `#efe8d9` |
| 卡片/顶栏 | `#fffdf8` |
| 边框 | `#e5ddcc` |
| 主文字 | `#4a4438` |
| 次要文字 | `#8d8574` |
| 主色（淡蓝） | `#5b9bd5` |
| 主色悬停 | `#4a8bc4` |
| 浅蓝底/选中 | `#e8f1f8` |
| 链接 | `#3f7fb5` |
| 成功 / 警告 / 错误 | `#6aa84f` / `#e6a23c` / `#d9534f` |

配色设置支持切换三套主题：`米色+淡蓝`（默认）、`纯白+淡蓝`、`清新绿`，通过顶栏「配色设置」切换，偏好存本地。

## 4. 导航与图标
- 侧边栏 7 个菜单项：首页、教师工作台、课堂智能助手、智能备课台、体质健康分析、AI 动作识别、系统设置。
- 菜单项前置线性图标（SVG，18px），分组可折叠（展开/收起）。
- 当前访问页高亮（浅蓝底 + 主色左边框）。

## 5. 组件规范
- **卡片**：白/米白底、圆角 10px、轻阴影；用于信息模块与表单分组。
- **按钮**：主按钮主色底白字；次按钮白底主色描边；危险操作用错误色。
- **表格**：表头浅底、细分隔线，行悬停浅蓝底。
- **表单**：标签在上、输入框在下，聚焦主色描边。
- **标签/徽章**：浅色底 + 对应文字色。
- **图表**：ECharts，配色沿用主色系。

## 6. 交互
- 破坏性操作（删除、清空）需二次确认。
- 动态效果轻量（随机点名、秒表计时用少量 JS）。
- 反馈统一用顶部提示条（成功/错误）。
