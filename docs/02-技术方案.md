# 技术方案

## 1. 技术选型
| 用途 | 选型 |
|---|---|
| 后端 | Python 3.10+ / Flask |
| 数据库 | SQLite（SQLAlchemy ORM） |
| 前端 | HTML + CSS + 轻量 JS（Flask 模板渲染 Jinja2） |
| 图表 | ECharts（本地 `static/vendor/echarts.min.js`） |
| AI 文本 | DeepSeek `deepseek-chat`（OpenAI 兼容接口） |
| AI 视觉 | DeepSeek `deepseek-v4-flash-vision-exp` |
| 视频抽帧 | OpenCV（`opencv-python-headless`） |
| 表格导入 | `openpyxl` |

## 2. 系统架构
```
浏览器（米色+淡蓝界面）
        │
   Flask 后端（Python）
   ├── routes/          各模块页面与接口（蓝图）
   ├── services/        AI 调用、体测评分、视频抽帧、设置等
   ├── models.py        SQLite 数据表（ORM）
   ├── security.py      登录/权限
   └── static/ uploads/ 样式、图表、上传的视频与附件
        │
   SQLite 数据库（data/）  +  DeepSeek API（AI）
```

## 3. 目录结构
```
├── app.py              # 入口 + 应用工厂
├── config.py           # 配置
├── extensions.py       # db 等扩展实例
├── models.py           # 数据表
├── security.py         # 登录装饰器/密码
├── requirements.txt    # 依赖
├── start.bat           # 一键启动
├── routes/             # 蓝图（auth/home/workbench/...）
├── services/           # 业务逻辑
├── templates/          # 页面
├── static/             # 样式/JS/上传文件
├── data/               # 数据库与静态数据
├── docs/               # 文档
└── 开发日志/           # 每日日志
```

## 4. 关键实现约定
- 单机登录：`session` 会话 + 默认账号，预留多人（`users` 表）。
- AI 调用统一封装在 `services/ai.py`、`services/vision.py`，密钥存数据库设置表。
- 体测评分逻辑封装在 `services/fitness_scoring.py`，评分表数据放 `data/`。
- 上传文件存 `static/uploads/`，抽帧图片存 `static/uploads/frames/`。
