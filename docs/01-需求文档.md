# 需求文档

## 1. 产品定位
面向**高校体育教师**的网页端 AI 教学辅助平台，**无学生端**，覆盖「课前备课 → 课中教学 → 课后分析」完整闭环，适配高校公共体育课程教学场景。

## 2. 已确认的核心决策
| 事项 | 决策 |
|---|---|
| 主色调 | 米色为主 + 淡蓝点缀，简洁直观 |
| AI 实现 | 接入真实大模型 DeepSeek |
| 使用规模 | 先单机演示版，架构预留多人扩展 |
| 运行环境 | Windows 电脑，浏览器访问 |
| 动作识别做法 | 视频抽帧 + AI 视觉分析 |
| 平时成绩 | 满分 100 分，按考勤 + 答题打分，比例可在设置里调整（默认考勤 60 + 答题 40） |
| 教学资源 | 资料库：上传文件 + 分类检索，供备课参考 |

## 3. 功能模块（共 5 个）

### 模块 1：教师工作台（基础数据）
- 教师课表：录入/编辑每周授课课表（课程名、时间、授课班级）。
- 学生名册：Excel/CSV 批量导入 + 手动录入，按行政班分班，维护学生信息（姓名、学号、性别）。
- 教学进度：教师工作台独立标签（学生名册 → 教学进度 → 教学反思 → 听课记录 → 教师待办），按行政班维护课时（手动添加/编辑/删除 + 进度表导入），作为学情分层「关联课时」下拉的数据源；删除课时保留历史分层归档。
- 教学反思：录入/归档，可绑定「班级 + 课程 + 时间 + 教案」。
- 听课记录：录入/归档，可绑定「班级 + 课程 + 时间」。
- 教师待办：增删改查 + 分类（备课/教学/教研/其他）。

### 模块 2：课堂智能助手（课中，2 个子页面，菜单固定展开）
- **学生考勤＋随机抽提问**：按课表自动带出该班学生名单，一键标记出勤/缺勤/请假/迟到，自动统计；随机抽取学生作答，带点名动画，记录作答情况。
- **学生平时成绩**：满分 100 分，按考勤 + 答题情况打分，两部分比例可调（默认 60 + 40）；按班级 + 学年筛选，导出 Excel（学号/姓名/考勤分/答题分/总分/评级）。

### 模块 3：智能备课台（课后备课，AI 核心）
- 教学资源：资料库，上传/管理教案模板、教学视频、图片、文档等，分类检索，AI 生成教案时可参考。
- 教学进度表上传导入：资料库上传标准 Excel 进度表（兼容旧版 Word）自动识别 → 预览课时列表 → 在预览页选择绑定班级/课程名称/授课项目/授课地点并核对后批量同步至课时管理；支持追加/覆盖导入（追加课次冲突高亮并禁止导入），源文件归档溯源、资源库与课时管理双向跳转（来源标记 `source_type`：manual / schedule_import）。
- AI 教案生成与修订：输入教学主题、课时、课标要求 → DeepSeek 生成结构化教案；结合已有教案 + 历史反思 + 学情 → 智能修订。
- 教案版本留存与回溯：每次生成/修订自动存版本，可查看历史、可恢复。
- 配套学习单 / 备课成果管理：统一收纳教案等备课产出，根据教案自动生成课前/课中/课后一体化学习单，支持成果预览、编辑、导出下载、复用与检索。
- 班级-运动项目关联配置：在学生名册「班级管理」新增/编辑班级时多选绑定运动项目，列表展示运动项目列；学情分层页面的运动项目下拉数据源取自该绑定（不允许在分层页直接新增绑定）；分层按「行政班 + 运动项目 + 课时」三元组（课时取自教学进度）；未配置绑定/课时则提示前往班级管理/教学进度配置；历史分层数据归档保留；AI 生成读取运动项目输出专项分层作业。

### 模块 4：体质健康分析（课后数据）
- 5 个子页面：体测评分录入、体质数据查询、体质统计报表、体质预警名单、体质报告导出。
- 历史体测数据导入 + 现场录入：Excel/CSV 批量导入 + 手动现场录入（带标准模板下载与行级错误校验）。
- 自动评分：内置《国家学生体质健康标准》大学组评分标准，按性别/项目自动算分与等级。
- 图表呈现：等级分布环形图、历年趋势折线图、单项分布柱状图（ECharts）。
- 体质预警：自动标出不及格/单项薄弱学生，分级（高危/关注）并说明原因。
- 报告导出：班级 Excel 报表、打印友好 PDF 报告。

### 模块 5：AI 动作识别（课后诊断，6 个子菜单）
1. **上传视频**：单视频上传（选学生/项目/技术动作）；批量上传（多选视频、统一项目与技术动作、按文件名「姓名.mp4」自动匹配学生库，未匹配标黄仍分析）；固定 MediaPipe 分析（未安装提示 not_install，识别不到人体提示 no_human）；批量异步队列 + 进度条 + 失败清单。
2. **识别历史**：全部诊断记录列表（学生/项目/技术动作/时间/状态），按班级/项目/学生/时间筛选；查看视频唤起单人诊断弹窗、删除、单条导出 PDF。
3. **常见错误汇总**：按「班级 → 项目 → 技术动作」筛选，按**错误类型**归类（不按学生逐条）；同一项目内不同技术动作的同类错误合并，条目含涉及学生、涉及技术动作、统一描述与统一建议；顶层概览 + 错误频次环形图/柱状图；点击学生姓名跳转单人弹窗；导出班级汇总 PDF。
4. **动作诊断报告库**：按班级/项目/学生/年份筛选，预览单人报告、下载 PDF、批量勾选导出多个学生 PDF。
5. **专项训练方案**：基于常见错误汇总自动生成班级针对性训练方案（训练目标/每条错误对应练习/课时安排/练习要点），可保存、编辑、导出 PDF；错误更新后可重新生成。
6. **学生动作成长档案**：以学生为主线纵向对比多次诊断，时间线 + 关节角度变化趋势图（ECharts 折线）+ 错误演变，点击某次记录唤起单人弹窗。
- 单人诊断弹窗 `renderActionModal` 为公共组件，识别历史/错误汇总/报告库/成长档案共用。
- 数据源为 `action_analyses` 诊断记录（含技术动作 `technique_action`、状态 `status`）。

## 4. 范围说明
- 无学生端、无学生登录。
- 无「学情数据中心」模块（已删除）。
- 第一版以单机可用为目标，多人使用与云端部署为后续扩展。
